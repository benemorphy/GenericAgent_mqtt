## 6. 改进建议

### 优先级 P0 - 紧急修复
1. **部署 supervisor_monitor**: 排查 `agentmain --reflect` 启动链路，确保监控脚本定期运行。可先从手动启动验证
2. **修复 WebSocket 8001**: 检查 Gateway WebSocket 配置，确保 board_service 的心跳和实时通信正常
3. **修复 DB Schema**: 定位 `ORDER BY id` 报错的SQL查询所在代码路径，添加缺失的 `id` 列

### 优先级 P1 - 重要改进
4. **Scheduler 开机自启**: 配置 scheduler 在系统启动时自动运行（注册为Windows计划任务或系统服务），避免延迟启动导致任务跳过
5. **监控告警机制**: 为 supervisor_monitor 增加异常告警通道（如飞书Bot通知），而非仅写日志
6. **日志轮转**: 为 gateway.log 等大日志文件增加轮转机制，防止磁盘写满

### 优先级 P2 - 优化建议
7. **LLM JSON 解析容错**: 在技能学习流程中增加JSON解析失败后的重试或降级逻辑
8. **健康检查报告持久化**: 确保 health_check 等定时任务执行后正确写入报告到 `done/` 目录
9. **磁盘空间预警**: 设置磁盘使用率>85%时通过监控系统发出预警
10. **定时任务积压处理**: 考虑增加"积压任务补执行"机制，当 scheduler 延迟启动时，对关键任务（如 health_check）仍尝试补执行而非直接跳过
