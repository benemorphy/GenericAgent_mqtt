# problem_selection_sop — 科学问题选择与决策分析
#
# 来源: knowledge-work-plugins/bio-research/scientific-problem-selection
# 适用: 选择研究课题/评估项目可行性/做复杂决策
#
# 9步工作流: 直觉泵 -> 风险评估 -> 优化函数 -> 参数策略 ->
#            决策树 -> 逆境规划 -> 问题反转 -> 综合叙事 -> 元框架

## Step 1: 直觉泵(Intuition Pumps) — 产生创新想法
# 三支柱 x 两维度 = 6象限:
#   支柱A: Perturbation(扰动)  — Logic / Technology
#   支柱B: Measurement(测量)   — Logic / Technology
#   支柱C: Theory/Computation  — Logic / Technology
#
# 操作为用系统性提问激活每个象限:
#   - 这个领域现在用什么方法? 能用不同逻辑做吗?
#   - 有没有新工具可以打开新可能?
#   - 计算结果能否取代/补充实验?
#
# 输出: 问题创意文档(1-2页)

## Step 2: 风险评估
# 两轴评估:
#   X轴: 成功概率   Y轴: 成功影响力
# 识别核心假设, 按"假设会在何时读出结果"排序
# 输出: 风险评估矩阵

## Step 3: 优化函数 — 定义成功指标
# 项目分类:
#   A. 理解生物学如何工作(基础认知)
#   B. 启用新实验/能力(工具/技术)
#   C. 解决实际问题(发明/应用)
# 每种类型对应不同评估指标
# 输出: 影响评估文档

## Step 4: 参数策略 — Fix One, Float the Rest
# 核心原则: 固定一个"神圣"参数, 让其他浮动
# 识别项目参数: 系统/方法/应用/环境/时间
# 选择固定哪一个, 哪个浮动
# 输出: 参数策略文档

## Step 5: 决策树 — 规划决策点
# 概念: 高度舞蹈(Altitude Dance) — 在不同抽象层级切换
# Level 0: 具体实现细节
# Level 1: 方法选择
# Level 2: 实验设计
# Level 3: 研究问题
# Level 4: 领域方向
#
# 在卡住时切换层级, 避免在错误层级死磕
# 输出: 决策树地图

## Step 6: 逆境规划 — 准备危机应对
# 核心认知: "逆境是迟早要来的危机——别浪费它"
# 预设失败模式: 技术不工作/假设错误/被抢先/合作中断/资金断链
# 每种模式设计应对策略
# 输出: 逆境剧本

## Step 7: 问题反转 — 卡住时从反面思考
# 三种反转策略:
#   1. Unfix参数: 让一个"神圣"参数浮动
#   2. 目标替代: 达不到目标A? 设一个可比的目标B
#   3. "我有答案, 问题是什么?": 反直觉框架
# 输出: 问题反转分析

## Step 8: 综合叙事 — 整合成连贯故事
# 故事结构: 设置/问题/新方法/迭代/结论/热情
# 输出: 项目沟通材料包

## Step 9: 元框架 — 编排1-8步
# 决定走完整流程还是仅用单个技能
# [完整流程]: 新项目/重大转向/申请资助
# [单个技能]: 特定阶段/快速咨询/更新部分

## 适用人群
# 研究生: 选课题/资格考试/组会 (Focus 1-3, 9)
# 博士后: 新职位/独立项目/申请 (Focus 全流程)
# PI: 新方向/指导学生/资助周期 (Focus 1,3,4,6)
# 创始人: 初创/重大转向/投资人 (Focus 1-4, 8)
