# brainstorming_sop — 发散-收敛式头脑风暴
#
# 来源: knowledge-work-plugins/product-management/brainstorm
# 适用: 探索新想法/解决问题/创造性挑战
#
# 流程: 定义 -> 发散 -> 收敛 -> 建议

## Phase 1: 定义问题空间
# 先明确:
#   - 核心问题或目标(一句话)
#   - 约束条件(时间/资源/技术)
#   - 成功标准(什么样算好想法)
#   - 参与者/利益相关者
#
# 如果用户只有模糊主题:
#   - 通过追问收窄范围
#   - 提供2-3个可能方向选项

## Phase 2: 发散(Diverge) — 生成多种方案
# 核心规则: 不评判, 不筛选, 越多越好
# 技巧:
#   - 三支柱法(同problem_selection): 从Perturbation/Measurement/Theory三方向发散
#   - 反转法: "如果反过来会怎样?"
#   - 类比法: "其他领域怎么解决类似问题?"
#   - 极端法: "如果资源无限会怎么做?" / "如果资源为零会怎么做?"
#
# 典型产出: 8-15个方向性想法

## Phase 3: 收敛(Converge) — 按标准筛选
# 评估维度:
#   可行性: 技术/资源/时间上可行吗?
#   影响力: 能产生多大效果?
#   风险: 最大失败代价是什么?
#   新颖度: 是否真正创新?
#
# 筛选策略:
#   [选项少(≤5)]: 直接讨论每个利弊
#   [选项多(>5)]: 先分组归类, 再按评估维度打分
#
# 典型产出: 3-5个可行方向

## Phase 4: 形成建议
# 每个方向输出:
#   - 名称和一句话描述
#   - 可行性评级 + 风险点
#   - 预期影响
#   - 下一步行动(最小验证步骤)
#   - 备选/退路
#
# 排列建议: 按可行性x影响力排序

## 错误处理
# [无想法]: 从最近类似问题的解法开始, 逐步扩大范围
# [想法太多]: 先分组归类, 每组选代表
# [卡在发散]: 切换视角(用户/技术/商业)
