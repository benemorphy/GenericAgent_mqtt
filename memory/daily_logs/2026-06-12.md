## 关键坑点 (未来参考)
- **file_patch 多行匹配会静默删行**: patch multi-line old_content 时，如果源文件中有未被 old_content 包含的中间行，patch 静默成功但中间行被删除。`BaseSession.__init__` 的 `self.user_agent` 就这样被误删，导致 NativeOAISession 初始化链式崩溃。
- **GenericAgent NativeToolClient 封装**: 不暴露 `.model`/`.switch_model()`，路由集成需加 proxy property，否则 `'NativeToolClient' object has no attribute 'model'`。
- **NativeOAISession 继承链**: NativeOAISession -> NativeClaudeSession -> BaseSession。BaseSession 必须设置 `user_agent` 否则 NativeClaudeSession.__init__ 报错 (AttributeError)。
- **agentmain.load_llm_sessions**: 空 session 列表需要先设 `self.llmclient = None` 避免除零错误，stapp.py 有 None 检查。
- **MixinSession llm_nos**: 使用字符串名而非索引时需要已有同名 session，否则 StopIteration 被 except:pass 吞静默。
