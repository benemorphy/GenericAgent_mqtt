# 两种启动方式对比：`python launch.pyw` vs `streamlit run frontends\stapp.py`

## 概述

该项目提供两种启动方式：
- **`python launch.pyw`** — 桌面原生窗口包装版
- **`streamlit run frontends\stapp.py`** — 纯 Streamlit Web 界面版

两者共享相同的 Streamlit 前端（`stapp.py`），但启动方式和使用体验有显著差异。

---

## 详细对比

| 对比维度 | `python launch.pyw` | `streamlit run frontends\stapp.py` |
|:--|:--|:--|
| **本质** | 桌面原生窗口包装器 | 纯 Streamlit Web 界面 |
| **UI 载体** | `pywebview` 创建的系统原生窗口（Windows WebView2 / macOS WebKit），**独立桌面应用** | 浏览器中访问 `localhost` 的 Web 页面 |
| **窗口控制** | 固定在屏幕右侧，600×900px，可调整大小，无浏览器工具栏 | 浏览器全权控制，无固定位置/大小 |
| **Streamlit 启动** | 自动子进程启动，自动寻找空闲端口 | 手动用 `streamlit run` 命令启动 |
| **JS ↔ Python 双向通信** | ✅ **有！** `inject()` 可直接向网页输入框注入文本；`PASTE_HOOK_JS` 拦截剪贴板图片/文件 | ❌ 无，仅通过 Streamlit 原生组件通信 |
| **空闲监控** | ✅ **有！** `idle_monitor` 线程每 5 秒检查，用户超过 30 分钟未回复则自动注入任务 | ❌ 无 |
| **Bot 启动** | ✅ 支持通过命令行参数启动多平台 Bot：`--tg`（Telegram） `--qq` `--feishu` `--wecom` `--dingtalk` 以及 `--sched`（计划任务） | ❌ 无 |
| **启动命令复杂度** | 简单：`python launch.pyw`，还可加可选参数 | 需手动指定 server 参数 |
| **适用场景** | 桌面应用直接使用，开箱即用，后台能力强 | Web 界面调试或远程访问 |

---

## 架构示意图

```
python launch.pyw
  │
  ├── 1. 启动子进程 → streamlit run frontends/stapp.py（自动分配端口）
  │
  ├── 2. 创建 pywebview 原生窗口 → 加载 http://localhost:{port}
  │      └── 窗口固定在屏幕右侧，600×900px
  │
  ├── 3. 启动空闲监控线程（idle_monitor）
  │      └── 30分钟无交互 → 自动注入任务
  │
  └── 4. [可选] 启动 Bot 后台服务
         ├── --tg  → Telegram Bot
         ├── --qq  → QQ Bot
         ├── --feishu → 飞书 Bot
         ├── --wecom → 企业微信 Bot
         ├── --dingtalk → 钉钉 Bot
         └── --sched → 计划任务调度器
```

---

## 通俗解释

### `python launch.pyw` — 桌面应用模式
相当于**把一个 Streamlit Web 应用打包成了原生桌面窗口**，并附带多种"后台能力"：

1. 先**默默在后台**用 `subprocess` 启动 Streamlit 服务
2. 然后用 `pywebview` **创建一个原生桌面窗口**（无浏览器工具栏/地址栏），看起来像个正经的桌面软件
3. 额外添加了**空闲监测**（你离开 30 分钟它就自动干活）、**剪贴板拦截**（直接粘贴图片/文件）、**Bot 启动**等功能
4. 窗口**自动贴右边**，位置固定，视觉上是个整洁的小助手窗口

### `streamlit run frontends\stapp.py` — Web 模式
**原始的 Streamlit Web 方式**：
- 在浏览器中打开，地址栏能看到 `localhost:8501`
- 没有任何额外的桌面特性或后台功能
- 适合调试、远程访问（比如从另一台电脑连过来）

---

## 一句话总结

> **`python launch.pyw` = 桌面原生外壳 + 后台 Streamlit + 空闲自动任务 + Bot 支持**，是把 Streamlit 包装成**真正的桌面应用**；而 `streamlit run stapp.py` 只是**单纯启动 Web 界面**，没有额外包装。
