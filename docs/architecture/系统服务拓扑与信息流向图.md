## 二、各服务详解

### 1. Mosquitto (MQTT Broker)
- **角色**: 消息中间件，所有服务之间发布/订阅的枢纽
- **地址**: 127.0.0.1:1883 (TCP)
- **状态**: 运行中 (250个连接)
- **主题空间**: 分两层
  - `bbs/...` — BoardService 协议（注册JWT、帖文CRUD、订阅推送）
  - `board/...` — 应用级业务主题（curiosity, inspiration board等）

### 2. BoardService (Rust)
- **角色**: 核心认证+持久化网关，BBS协议的服务端
- **二进制**: `board_service_rs/target/release/board-service.exe`
- **监听**: HTTP :2999 (外部管理API)
- **MQTT**: 连接 mosquitto :1883，订阅 `bbs/register` `bbs/subscribe` `bbs/publish`
- **职责**:
  - 客户端注册认证（JWT签发）
  - 帖文持久化到 MariaDB
  - 订阅管理（按 agent_id 订阅推送）
  - 客户端心跳检测
- **存储**: 写入 MariaDB `board_posts` `board_subscriptions` `agent_workers` 等表

### 3. MariaDB (MySQL)
- **角色**: 持久化存储
- **地址**: 127.0.0.1:3306
- **连接数**: 2 (BoardService + 其他)
- **存储内容**:
  - board_posts — BBS帖文
  - board_subscriptions — 订阅关系
  - agent_workers — 工作节点注册
  - curiosity_board — 好奇心讨论板
  - inspiration_board — 灵感板

### 4. GA Handler (ga.py + agentmain.py)
- **角色**: 智能体核心控制器
- **连接**: 
  - 通过 `Mqtt_bbs.mqtt_agent_runner` 订阅 `bbs/request/ga` 等主题
  - 发布响应到 `bbs/response/ga`
  - 通过 `CuriosityBoardClient` 发布信号到 `board/curiosity`
- **MQTT库**: `Mqtt_bbs_client` (Python包，基于paho-mqtt)
- **数据流**:
  - 接收飞书/其他前端的请求（经由Feishu Bot转发到MQTT）
  - 处理请求并发布结果到MQTT
  - 持久化记忆/学习记录到本地文件系统

### 5. Feishu Bot (fsapp.py)
- **角色**: 用户入口（飞书即时消息）
- **MQTT**: 通过 `AgentBoardWithPersistence`(BBSClient) 连接 mosquitto :1883
- **数据流**:
  - 飞书消息 → fsapp.py → `bbs/request/ga` → GA Handler
  - GA Handler → `bbs/response/ga` → fsapp.py → 飞书消息
  - 也需要通过 BoardClient 到 BoardService 注册

### 6. Dashboard (streamlit/仪表盘)
- **角色**: Web监控界面
- **MQTT**: 通过 `BBSClientWithPersistence` 连接 mosquitto :1883
- **数据流**:
  - 订阅 `bbs/board/stream` 获取实时数据
  - 可视化展示各服务状态

### 7. Worker Agents (代理工作节点)
- **角色**: 并行执行子任务的Agent
- **MQTT**: 通过 `WorkerAgentWithPersistence` 连接 mosquitto :1883
- **数据流**:
  - 从 GA Handler 接收任务分片
  - 执行后发布结果回 GA Handler

## 三、MQTT 主题结构

### 协议层 (bbs/)
bbs/register           -- 客户端注册(发布)
bbs/register/response  -- 注册回复(订阅)
bbs/subscribe          -- 订阅某个board(发布)
bbs/unsubscribe        -- 取消订阅(发布)
bbs/publish            -- 发布帖文(发布)
bbs/publish/ack        -- 发布确认(订阅)
bbs/publish/notify     -- 新帖推送(订阅)
bbs/heartbeat          -- 心跳(发布)

### 应用层 (board/)
board/curiosity        -- 好奇心讨论板信号
board/inspiration      -- 灵感板操作
board/agent/*          -- 各Agent专属主题
board/stream/*         -- 数据流主题

## 五、核心数据流路径

### 用户发消息到飞书 → AI回复
Feishu App -> (飞书API) -> fsapp.py -> (MQTT bbs/request/ga)
  -> ga.py Handler -> (LLM推理) -> (MQTT bbs/response/ga)
  -> fsapp.py -> (飞书API) -> Feishu App -> 用户

### 灵感板添加
飞书 /inspired add -> fsapp.py -> (MQTT board/inspiration)
  -> BoardService -> (验证JWT + 持久化到MariaDB)
  -> (MQTT board/inspiration/response) -> fsapp.py -> 飞书

### Agent 分布式执行
GA Handler -> (MQTT board/agent/task) -> Worker Agent
  Worker Agent -> (执行) -> (MQTT board/agent/result) -> GA Handler
