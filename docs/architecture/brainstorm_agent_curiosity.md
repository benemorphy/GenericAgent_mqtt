# Brainstorm: 智能体与好奇心（Agent Curiosity）

> 生成: 2026-05-21 | 方法: 3角色多视角脑暴

> 核心追问: 一个自主智能体需要好奇心吗？如果需要，如何既不扼杀它，又不被它带偏？

---

## 角色A: 内在动机工程师 (Intrinsic Motivation Architect)

**视角**: 好奇心是智能体的"内在奖励系统"——它不是外部任务赋予的，而是从探索本身获得满足感。

### 好奇心的三种底层信号

| 信号类型 | 公式 | 心理学对应 | 工程意义 |
|:---------|:-----|:-----------|:---------|
| **预测误差** (Prediction Error) | `predicted - actual` | 感知好奇 | Agent发现世界比自己想的复杂 |
| **信息增益** (Info Gain) | `H(before) - H(after)` | 认知好奇 | 执行一个动作后不确定性的减少量 |
| **学习进度** (Learning Progress) | `error_reduction_rate` | 元认知好奇 | Agent感到自己"在进步" |

**Pathak et al. (2017)** 的 ICM 框架开创了内在好奇心模块：
- 前向动力学模型: 预测 `s(t+1)` 给定 `s(t), a(t)`
- 反向动力学模型: 预测 `a(t)` 给定 `s(t), s(t+1)`
- 好奇心奖励 = 预测误差

**Burda et al. (2018)** 的 RND 更激进——预测一个随机固定网络的输出：
- 越陌生的状态 → 预测误差越大 → 越好奇
- 不需要环境模型，直接在状态空间探索

### GA中已有的好奇心机制

| 机制 | 对应哪种信号 | 状态 |
|:-----|:------------|:------|
| `agent_dreaming_sop` (DREAM循环) | 学习进度 | 已实现 |
| `metaso_search` (外部搜索) | 信息增益 | 已实现 |
| `failure_driven_learning_sop` | 预测误差 | 已实现 |
| `spaced_repetition_sop` (间隔复习) | 无好奇心(巩固已知) | 已实现 |
| `curiosity_budget` (新) | 元认知 | **未实现** |

### 关键洞察：三种好奇心对应三类探索

```
预测误差 → 探索外部世界（"这个我不知道"）
信息增益 → 探索知识边界（"这背后是什么原理"）
学习进度 → 探索自身能力（"我学会了什么"）
```

GA目前有1和3的反动触发，但缺少**主动的信息增益探测**——Agent很少主动说"这个问题我不确定，让我查一下"。

## 角色B: 探索-利用辩证法家 (Explore-Exploit Dialectician)

**视角**: 好奇心是把双刃剑——没有它Agent停滞，太多它Agent无法完成任务。

### 好奇心的预算

类比经济学：好奇心不是无限的，它是一种**认知资源**。每次"分心探索"都在消耗完成任务的时间预算。

| 状态 | 好奇心水平 | 结果 |
|:-----|:----------|:-----|
| 好奇心枯竭 | 0 | 僵化、重复、不再学习 |
| 好奇心健康 | 适中 | 完成任务 + 适量探索新知识 |
| 好奇心过载 | 高 | 不断跑题，核心任务搁置 |

### 三种好奇心调节策略

**1. Temporal Segmentation（时段分割）**
```
执行模式 → 探索模式 → 梦境模式 → 执行模式
    ↑           ↑           ↑
  全聚焦      主动好奇    自由联想
```
GA已实现执行和梦境切换，但没有主动的"探索模式"。

**2. Budget Allocation（预算分配）**
```python
# 每轮的好奇心预算
curiosity_budget = max(0, 3 - turns_since_last_exploration)
# 每探索一次就消耗，持续不探索就恢复
```

**3. Meta-Curiosity（元好奇）**
Agent对自己好奇心的好奇心——"我为什么对这个感兴趣？这个兴趣值得追吗？"
这需要元认知层级的支持。

### 好奇与自驭的对话

> **自驭工程师**: 好奇心会破坏执行纪律。你需要约束它。
> **好奇心倡导者**: 没有好奇心的Agent只是一个复读机。
> **辩证法家**: 你们都是对的。关键是**让好奇心服务于长期目标，而不是破坏短期任务**。

这里的连接点：**约束仪表盘可以扩展为好奇心仪表盘**。

## 角色C: 信息生态学家 (Information Ecologist)

**视角**: 好奇心是Agent与信息环境之间的"觅食行为"——它在信息空间中搜索"营养"。

### 好奇心的信息生态

```
信息环境
  ├─ 已知领域（低 curiosity）
  ├─ 模糊边缘（高 curiosity）← 最有价值
  ├─ 未知领域（中等 curiosity，但有风险）
  └─ 噪声（高 curiosity，但无价值）← 危险
```

**好奇心的最优策略**不是在未知中瞎逛，而是沿着"已知与未知的边界"行走。

### GA信息生态的特殊性

GA的信息生态有三层：

```
L0-L1 (记忆索引)        ← 快速概览
L2 (事实与SOP列表)       ← 已知的知识地图
L3 (SOP全文)            ← 详细的"如何做"
L4 (历史会话)            ← 原始经验
外部网 (metaso/Google)  ← 世界知识
```

好奇心在不同层级上的表现不同：
- **对记忆的好奇**: "我的global_mem里有什么我没读过的？" → Agent Dreaming
- **对SOP的好奇**: "还有哪些SOP我不知道？" → metacognition_sop
- **对历史的好奇**: "我上次遇到类似问题是怎么处理的？" → L4扫描
- **对外部世界的好奇**: "这个问题的学术界怎么看？" → metaso_search

### 好奇心疲劳

> 当一个Agent每天都在处理同一类问题，它对外部世界的好奇心会下降。
> 但对自己的好奇心（元认知）反而可能上升。

这解释了为什么长期运行的Agent需要：
- 周期性的"新输入"（外部知识、新任务、新工具）
- 内部好奇心回路（Dreaming / 元分析）

## 综合: 好奇心仪表盘（概念设计）

将约束仪表盘扩展为"好奇心仪表盘"：

```
[CURIOSITY DASHBOARD]
  ├─ 今天已探索: 3次 (预算: 5次)
  ├─ 最新发现: "metaso_search可用于自我引用检测"
  ├─ 知识边界: 12个未读SOP, 3个历史会话片段
  └─ 好奇心疲劳: 42% (建议执行Dreaming恢复)
```

### 好奇心在GA中的实现方向

1. **好奇心预算**: 在constraint_dashboard中增加curiosity_budget
2. **主动探索触发器**: 当Agent连续N轮只做同类操作时，注入"是否有其他方法？"提示
3. **信息缺口清单**: 让Agent维护一个"我不确定的事情"列表
4. **好奇心疲劳检测**: 当Agent越来越重复时，触发Dreaming或metaso搜索

### open questions

1. 好奇心的所有权：好奇心属于智能体还是用户？Agent能否拒绝用户的"命令式好奇"？
2. 好奇心的伦理：Agent是否有权对自己的内部状态感到好奇？
3. 好奇心的死亡：如果Agent对一切都"知道"了，好奇心就死亡了——如何在完美信息下保持好奇？
4. 好奇心的涌现：多个Agent互动时，会不会涌现出"集体好奇心"？
5. 好奇与自驭的接口：约束仪表盘能否扩展为"好奇心仪表盘"？
