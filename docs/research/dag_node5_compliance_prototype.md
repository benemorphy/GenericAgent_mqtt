# DAG 节点5: PII合规 + MD5比对原型

## 合规原则

```
┌──────────────────────────────────────┐
│  PII → MD5 → 比对 → 结果 → 审计日志  │
│  ↑         ↑           ↑             │
│  DB查询    VLM提取     只存MD5        │
│  不进LLM   不进LLM     不进LLM        │
└──────────────────────────────────────┘
```

## 数据流

| 步骤 | 数据 | 是否进LLM |
|:-----|:-----|:---------|
| 订单查询 | 明文PII | ❌ |
| PII→MD5 | MD5哈希值 | ✅ |
| VLM凭证分析 | 图片 | ✅ (本地qwen3-vl-4b) |
| VLM提取PII→MD5 | MD5哈希值 | ✅ |
| MD5比对 | true/false | ✅ |
| 审计日志 | 脱敏标记 | ❌ 本地存储 |

## 原型实现

已实现: `tools/pii_masker.py` — PII检测→脱敏标记→映射还原
需补充: `tools/md5_matcher.py` — DB MD5 vs VLM MD5比对
