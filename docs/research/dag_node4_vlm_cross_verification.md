# DAG 节点4: VLM凭证交叉对比

## VLM验证能力

| 凭证要素 | VLM能力 | 局限 |
|:---------|:--------|:-----|
| 身份证/头像 | ✅ 面部比对+篡改检测 | 形态攻击可绕过 |
| 签名 | ⚠️ 随机伪造高准确率 | 熟练伪造需动态特征 |
| 印章 | ✅ 结构/颜色/几何对齐 | 高分辨率伪造可通检 |

## 交叉验证流水线

```
图DB环内订单列表
  ↓ 逐个下载凭证图片
VLM提取: PII/印章/签名 → MD5
  ↓
跨订单比对: 身份证MD5 / 印章MD5 / 签名MD5
  ↓
发现重复身份证 / 重复印章 → vlm_links表写入
  ↓
图DB扩展 → 更大环 → 更多VLM验证
```

## 与现有集成

| 组件 | 角色 |
|:-----|:-----|
| `gui_vision` VLM后端 | 凭证图片分析 |
| `PII Masker` | 提取PII→MD5比对 |
| `vlm_links`表 | 新关联写入 |
| `Oxigraph` | 图扩展循环 |
