## 核心发现

**图片凭证伪造检测 = OCR语义验证 + CNN视觉取证 双流架构**

## 1. OCR验证层

| 技术 | 功能 | 实现 |
|:-----|:-----|:-----|
| 模板匹配 | 比对凭证格式/序列号/发行方 | Tesseract + 正则库 |
| 字体不一致 | 检测文字替换痕迹 | OCR字体比对 |
| 逻辑验证 | 条码+文本组合的业务逻辑 | 规则引擎 |

## 2. 深度学习视觉取证层

| 技术 | 检测目标 | 架构 |
|:-----|:---------|:-----|
| CNN频率域 | 修改痕迹(拼贴/复制) | Xception + FFT |
| ELA | 压缩率差异(拼贴检测) | Error Level Analysis |
| 迁移学习 | 跨数据集泛化 | 预训练模型微调 |

## 3. 融合检测流水线

```
输入图片 → 预处理(OpenCV) → OCR文本提取 → CNN视觉检查 → 交叉验证 → 可信度评分
                 ↓                 ↓              ↓
          二值化/去噪/纠偏   格式/字体/逻辑   拼贴/伪造痕迹
```

## 4. 与现有项目集成

| 现有能力 | 节点1产出 |
|:---------|:----------|
| `gui_vision` VLM坐标 | VLM定位凭证区域→传给OCR/CNN |
| PII Masker | OCR提取PII→MD5比对→脱敏 |
| MAS持久化 | 分发VLM分析任务→收集结果 |
