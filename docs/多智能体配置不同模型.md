# 多智能体配置不同模型

> 对不同的 Subagent 使用不同的大模型（如一个接 OCR 视觉模型、另一个接纯文本模型）

## 原理

当前系统天然支持多模型配置，核心链条：

```
mykey.py                    agentmain.py                   subagent
  │                              │                             │
  ├─ 定义 config A           ◄── 启动时扫描全部变量              │
  ├─ 定义 config B              含 'api'/'config'/'cookie'      │
  ├─ 定义 config C              按发现顺序→ llmclients[0..N]    │
  │                              │                             │
  │                              ▼                             ▼
  │                        --llm_no 0 → llmclients[0]    subagent A
  │                        --llm_no 1 → llmclients[1]    subagent B
  │                        --llm_no 2 → llmclients[2]    subagent C
```

## 关键参数：`--llm_no`

`agentmain.py` 的 `--llm_no N` 参数用于选择第 N 个 LLM session：

```python
# agentmain.py 中
parser.add_argument('--llm_no', type=int, default=0)
...
agent.next_llm(args.llm_no)  # 选择 llmclients[llm_no]
```

- 默认值 `0`，即不传参数时使用第一个 session
- 传入 `1` 则使用第二个 session，依此类推
- 循环取模：`self.llm_no = n % len(self.llmclients)`

## 操作步骤

### Step 1 — 在 mykey.py 中定义多个 session

```python
# ── 1号：视觉模型（OCR/看图）────────────────────────
native_claude_config_vision = {
    'name': 'vision-model',
    'apikey': 'sk-ant-<your-key>',
    'apibase': 'https://api.anthropic.com',
    'model': 'claude-opus-4-7',           # 多模态，能看图
    'fake_cc_system_prompt': True,
}

# ── 2号：纯文本模型（快速/便宜）────────────────────
native_oai_config_text = {
    'name': 'text-model',
    'apikey': 'sk-<your-key>',
    'apibase': 'https://api.openai.com/v1',
    'model': 'gpt-4o-mini',               # 纯文本
}
```

> agentmain.py 自动扫描 `mykey.py` 中所有变量名同时含 `'api'` / `'config'` / `'cookie'` 的变量。
> 两个 config 都会被加载：vision 在前（`llmclients[0]`），text 在后（`llmclients[1]`）。

### Step 2 — 启动 subagent 时指定模型

```bash
# OCR 智能体 → 视觉模型 (llmclients[0])
python agentmain.py --task 截图分析员 --input "你负责OCR识别截图" --llm_no 0 --bg

# 文本智能体 → 纯文本模型 (llmclients[1])
python agentmain.py --task 文本摘要员 --input "你负责总结长文章" --llm_no 1 --bg
```

### Step 3 — 通过 Dashboard 查看

启动 subagent_dashboard.py 后，每张 agent 卡片会显示当前使用的模型名。

```bash
streamlit run frontends/subagent_dashboard.py
```

## 进阶用法

### 使用 Mixin 故障转移

如果想为某个 subagent 配置主/备模型，可以用 mixin_config：

```python
mixin_config = {
    'llm_nos': ['vision-model', 'text-model'],   # 主 vision → 备 text
    'max_retries': 5,
    'base_delay': 0.5,
}
```

然后启动时指向 mixin（假设它在 `llmclients[2]`）：

```bash
python agentmain.py --task 高可用OCR --input "..." --llm_no 2 --bg
```

### 在启动面板中选择模型

Dashboard 侧边栏的「启动 Agent」面板已支持 `--llm_no` 参数选择模型。

## 常见问题

### Q: 怎么知道当前用的是哪个模型？
A: stdout.log 中会打印 `[MixinSession] Using session (xxx)` 或模型加载信息。Dashboard 的 agent 卡片上也会显示模型名。

### Q: 可以混用 Native 和非 Native session 吗？
A: Mixin 不允许。Mixin 要求引用的 session 全部是 Native 系列（NativeClaudeSession + NativeOAISession 可混），或者全部是非 Native，不能混搭。但独立 subagent 各自用不同的 session 类型完全没问题。

### Q: session 的加载顺序是什么？
A: agentmain.py 按 `mykeys.items()` 的遍历顺序加载，即变量定义顺序。先定义的变量在前（索引小）。
