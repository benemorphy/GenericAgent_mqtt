# arXiv:2605.12466 — Solve the Loop: Attractor Models for Language and Reasoning

**Authors:** Jacob Fein-Ashley, Paria Rashidinejad
**Subjects:** Machine Learning (cs.LG)
**Date:** May 2026

## Abstract
Looped Transformers offer a promising alternative to purely feed-forward computation by iteratively refining latent representations, improving language modeling and reasoning. Yet recurrent architectures introduce overhead in both training and inference. We present Attractor Models, a new architecture class in which a non-recurrent backbone proposes an output representation, and an attractor module refines it via fixed-point iterations. The backbone and attractor are trained jointly with implicit differentiation, decoupling solution accuracy from depth. Empirically, Attractor Models outperform existing models: a 770M parameter Attractor Model outperforms a 1.3B Transformer trained on twice the data, achieving up to 46.6% lower perplexity and 19.7% higher downstream accuracy. On iterative reasoning benchmarks, Attractor Models achieve 91.4% accuracy on Sudoku-Extreme (27M dimensions) where Claude and GPT-o3 fail entirely, and 93.1% on Maze-Hard (27M) where specialized recurrent models collapse on larger dimensions. Analysis reveals a phenomenon we term **equilibrium internalization**: as training progresses, the model learns to internalize the iterative reasoning, and the solver can be removed at inference time with little degradation.

## Key Contributions
1. **Attractor Model architecture**: Backbone + Attractor module with fixed-point iteration
2. **Implicit differentiation** training decouples depth from accuracy
3. **Equilibrium internalization**: Model learns to internalize recurrence
4. **770M outperforms 1.3B** Transformer on 2x data
5. **91.4% on Sudoku-Extreme** (27M), **93.1% on Maze-Hard** (27M)
