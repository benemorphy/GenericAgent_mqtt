# arXiv:2506.14782 — Integrating Dynamical Systems Learning with Foundational Models

**Authors:** Joseph Geraci, Bessi Qorri, Christian Cumbaa, Mike Tsay, Paul Leonczyk, Luca Pani
**Subjects:** Machine Learning (cs.LG)
**Date:** June 2025

## Abstract
We analyze two AI paradigms: DeepSeek-V3 (671B MoE LLM) exemplifying scale-driven generality, and NetraAI, a dynamical system-based framework for stability and interpretability on small clinical trial datasets. NetraAI combines **contraction mappings, information geometry, and evolutionary algorithms** to identify predictive patient cohorts. Features are embedded in a metric space and **iteratively contracted toward stable attractors** that define latent subgroups. A pseudo-temporal embedding and long-range memory enable exploration of higher-order feature interactions, while an internal evolutionary loop selects compact, explainable 2-4-variable bundles ("Personas"). An **LLM Strategist** acts as a meta-evolutionary layer observing Persona outputs, prioritizing variables, injecting domain knowledge, and assessing robustness. In case studies (schizophrenia, depression, pancreatic cancer), NetraAI transformed weak baseline models (AUC ~0.50-0.68) into near-perfect classifiers.

## Key Insights
1. Attractor-based dynamical system for clinical trial analysis
2. Contraction mapping → stable attractors define subgroups
3. LLM as meta-evolutionary layer (two-tier architecture)
4. Small dataset, high effect size
