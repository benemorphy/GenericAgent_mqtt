# problem_inversion_sop — 问题反转策略: "Turn It On Its Head"
#
# 来源: knowledge-work-plugins/bio-research/scientific-problem-selection/07-problem-inversion
# 适用: 卡住无法前进时, 从反面/侧面重新思考问题
#
# 核心原则: "当正面攻不上去, 不要硬攻, 翻过来看看"

## 策略1: Unfix参数(危机模式)
# 当项目执行中遇到常规障碍时:
#   - 找出当前最"神圣"的固定参数
#   - 问: "如果这个参数浮动, 会有什么替代方案?"
#   - 示例: 卡在空间转录组术中?
#     -> Unfix技术: 有其他方法测量细胞相互作用吗?
#     -> Unfix细胞类型: 肿瘤中还有什么相互作用?
#     -> Unfix环境: 在哪还有其他T细胞-APC相互作用?

## 策略2: 目标替代(Comparable Goal Substitution)
# 当目标A无法达成时:
#   - 不执着于目标A
#   - 问: "什么样的目标B也能算成功?"
#   - 目标是B不是降级——是换了一个等值但可行的方向
#   - 示例:
#     原目标: 证明机制X参与疾病Y
#     替代: 证明机制X不参与疾病Y(但发现其参与疾病Z)
#     替代: 证明机制X在系统中起什么作用(不限于Y)

## 策略3: "我有答案, 问题是什么?"
# 反直觉框架:
#   - 假设已经找到了一个解决方案, 然后倒推它解决的是什么问题
#   - 适用场景: 知道技术方法/工具, 但在寻找应用方向
#   - 示例:
#     答案: 我有一个超分辨率显微镜
#     问题: 什么生物学问题需要比传统显微镜高10倍的分辨率?
#
# 步骤:
#   1. 写下你拥有的工具/技术/资源
#   2. 假装它已经解决了某个大问题
#   3. 倒推: 那个问题长什么样? 谁会受益?

## 适用条件
# [反复卡住] - 正面尝试>=3次失败 -> 启动反转
# [方向模糊] - 有工具没应用 -> 策略3
# [目标太硬] - 目标A明显不可达 -> 策略2
