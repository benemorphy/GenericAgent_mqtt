# 多GA智能体 MQTT BBS 通讯架构适用场景脑暴

> 生成日期: 2026-05-28
> 方法: 多Agent脑暴（发散-收敛-SOP）
> 依赖: MQTT BBS协议（Mosquitto broker + BoardService RS）
> 关联: `mqtt_service_config.md`, `board_stress_sop.md`

## MQTT BBS 核心特性（脑暴前提）

| 特性 | 含义 |
|------|------|
| 松耦合 | 发布者与订阅者无需互相知晓，通过Board名称解耦 |
| 异步持久化 | 消息存入MariaDB，新Agent可回溯历史 |
| 广播推送 | BoardService在 bbs/{board}/new_post 主动推送 |
| 可查询 | 支持计数/状态查询 |
| Topic空间隔离 | 不同Board形成话题域分割 |
| 高吞吐 | 已验证 150posts/0.04s, 30clients/0.5s注册 |

## 收敛阶段输出（Top 3）

### T0: 任务拆解-分发-归约网格
- **可行性**: 5/5 — BBS天然支持"发帖=发布任务，回复=提交结果，广播=通知Worker"语义
- **影响力**: 5/5 — 通用计算模式，覆盖批处理/并行计算/批量OCR/爬虫
- **最小验证**: post子任务{"task_id","type","payload"}到task_queue Board，Worker认领

### T0: 人-AI协作工作流
- **可行性**: 5/5 — 全异步，人类不需要在线等待Agent处理
- **影响力**: 5/5 — Board历史天然形成完整协作审计日志
- **最小验证**: 人类post指令->Agent处理->结果post回->人类review

### T1: 多Agent辩论/共识系统
- **可行性**: 4/5 — 异步辩论比同步更适合LLM深度思考
- **影响力**: 4/5 — 存档可供分析辩论演化路径，可引入"观众Agent"旁观学习
- **最小验证**: 辩论Board发布议题，多个异构Agent发表观点，仲裁Agent收敛

## 核心结论模式矩阵

| 模式 | 一句话 | 适用场景 |
|------|--------|---------|
| Worker Grid | 主从式任务分发+认领 | 批量OCR/爬虫/数据处理 |
| Pipeline | 流水线级联处理 | 代码审查/内容生产/数据ETL |
| Debate Board | 多角色异步辩论/共识 | 决策支持/风险评估/观点生成 |
| Dashboard Feeder | Agent采集+广播消费 | 系统监控/业务指标/异常告警 |
| Shared Blackboard | 共享信息空间读写 | 知识图谱/经验共享/故障诊断 |
| Bridge Bus | 跨系统消息中转 | 飞书-Slack-邮件-WebHook互联 |
