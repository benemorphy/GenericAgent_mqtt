# skill_template_sop — 知识工作技能通用模板
#
# 来源: knowledge-work-plugins 多个skill提取的最佳实践
# 适用: 编写新的知识工作SOP时作为模板
#
# 模板结构:

## 元数据
# ---
# name: skill-name
# description: 一句话描述何时使用
# ---

## 1. Usage(使用方式)
# 命令格式和使用示例

## 2. Workflow(工作流 — 核心)
# 每一步必须满足:
#   [可执行] - 每个步骤是原子操作, 不能被拆得更细
#   [条件分支] - 每个步骤标注不同情况下的不同处理:
#     [情况A]: 处理方式
#     [情况B]: 处理方式
#   [用户交互点] - 什么情况需要问用户/什么情况可以直接做

## 3. 错误处理(必须包含)
# 通用模式:
#   [某步骤失败] -> 记录原因, 跳过并标注, 不中断整体流程
#   [无数据/无结果] -> 记录为0并继续, 不产生警告
#   [rate limit] -> 跳过, 记录到Sources
#   [矛盾数据] -> 特别标注, 而非掩盖

## 4. 输出格式
# 统一结构:
#   - 概述(范围/方法/时间/样本量)
#   - 发现(按优先级排列)
#   - 建议(可操作, 回连发现)
#   - 未尽事项(不确定性/后续)
#
# 置信度标注:
#   [High]   - 强证据, 多源交叉验证
#   [Medium] - 可信但需用户确认
#   [Low]    - 早期信号/推测

## 5. Approval Gates(批准门)
# 什么操作需要用户确认:
#   [写操作] - 修改/删除/发送 -> 需确认
#   [读操作] - 查询/分析/汇总 -> 可直接做
#   [边界操作] - 自动化/定时/跨系统 -> 需确认

## 6. Reference(参考)
# - gotchas(已知陷阱/反模式)
# - 示例(完整工作示例)
# - 相关技能
