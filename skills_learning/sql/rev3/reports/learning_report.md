## 知识模式

### 领域专有 (10个)
- [95%] 始终使用参数化查询或预编译语句来防止SQL注入攻击，避免直接拼接用户输入到SQL字符串中。
- [95%] SQL查询基础（SELECT、JOIN、子查询等核心语法）
- [90%] 在生成SQL查询时，应包含输入验证、分页辅助、风险分析和审计安全措施，以确保查询的安全性和可维护性。
- [90%] 数据库设计与规范化（表结构、索引、范式）
- [85%] SQL是一种用于管理关系数据库的领域特定语言，其标准发音为S-Q-L或sequel，设计用于结构化数据的查询和操作。
- [85%] SQL性能优化（查询计划、索引优化、慢查询调优）
- [80%] NoSQL数据库设计用于存储和检索非关系型数据，与SQL关系型数据库互补，适用于灵活模式和大规模数据场景。
- [80%] 事务与并发控制（ACID、锁机制、隔离级别）
- [75%] 选择数据库系统（如MySQL、Microsoft SQL Server）时，需考虑其开源/专有属性、功能特性和与SQL标准的兼容性。
- [75%] SQL安全实践（防注入、权限管理、数据加密）
